# PRD — 11.0 Sales Intelligence Core

**Status:** Core 11.0.1–11.0.4 implemented
**Depends on:** Mercado Livre orders, Inventory, Financial Intelligence and 9B Marketplace Settlement

## Goal

Provide one tenant-safe screen where a seller can understand an order, its payment, marketplace fee, net amount provenance and inventory state.

## Accepted decisions

- **11.0-D1:** one row per order by default; SKUs are grouped in a detail drawer. An item-level toggle may be added later.
- **11.0-D2:** net amount precedence is `REALIZED`, `RECONCILED`, `ESTIMATED`, then `UNAVAILABLE`. The UI never presents estimates as realized cash.
- **11.0-D3:** `/sales-intelligence` is a read/analytics route; `/orders` remains the operational route.

## In scope through 11.0.4

- Mercado Livre order identity, status, date and grouped SKUs.
- Payment status/value, marketplace fee and net amount with explicit source.
- Aggregated order stock state and item stock states in the drawer.
- Summary, filters, backend pagination, RBAC/capability and pt-BR/en-US.
- Swagger, OpenAPI, Redoc, tests and operational validation.

## Out of scope

- COGS, profit, margin, DRE, taxes and full cash/settlement UI.
- Shipping/fulfillment, labels, DANFE and complete timeline.
- Alerts, n8n, CSV/XLSX and item-level table mode.
- Raw provider payloads, tokens, secrets or frontend-supplied `tenantId`.

## Delivery

```text
11.0.1 — Foundation, contracts, permission/capability, route and UI shell
11.0.2 — Versioned financial intake and consolidated read model
11.0.3 — Sales queue, summary, filters and SKU drawer
11.0.4 — Performance, security, runtime docs and E2E smoke
```

The broader source package continues to 11.0.7, but this approved and completed Core ends at 11.0.4.
